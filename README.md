# Loan Approval Prediction

An end-to-end machine learning project that predicts whether a loan application
will be approved, based on applicant details like income, credit history,
employment status, and education.

## Overview

This project covers the full ML workflow: data cleaning, preprocessing,
model comparison, hyperparameter tuning, evaluation, and saving a deployable
model.

**Dataset:** 614 loan applications with a mix of numeric (income, loan amount)
and categorical (gender, education, property area) features, including real
missing values across multiple columns.

## What this project demonstrates

- Handling missing data differently for numeric vs. categorical columns
- Building a reusable preprocessing pipeline with `ColumnTransformer`
- Comparing multiple models (Logistic Regression, Random Forest) with
  cross-validation
- Hyperparameter tuning with `GridSearchCV`
- Saving a trained pipeline with `joblib` for later reuse
- Making predictions on brand new, unseen applicant data

## How to run

1. Clone this repo and set up a virtual environment:
   ```bash
   python -m venv venv
   source venv/bin/activate      # Windows: venv\Scripts\activate
   pip install -r requirements.txt
   ```

2. Train the model:
   ```bash
   python src/train.py
   ```
   This cleans the data, compares models, tunes the best one, evaluates it,
   and saves the final pipeline to `models/loan_approval_model.pkl`. Plots
   are saved to `outputs/`.

3. Predict on a new applicant:
   ```bash
   python src/predict.py
   ```
   Loads the saved model and runs a prediction on a sample applicant defined
   in the script — edit the values there to try your own.

## Results

After cross-validation and tuning, the final model achieves:
- **Test accuracy:** ~82%
- **Key predictive features:** Credit History, Applicant Income, Loan Amount

See `outputs/loan_feature_importance.png` for the full breakdown.
